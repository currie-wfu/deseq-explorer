DESeq2 gene explorer

Load one or more DESeq2 result files (CSV or TSV). Each file is one comparison. Files are read in this browser only and are never uploaded.

Data

Drop result files or a folder here
Expected columns: a gene column (gene, symbol, gene_id or the first column), log2FoldChange, padj, and optionally baseMean, pvalue and per-sample normalized counts. Sample groups are guessed from the sample names (for example rep1_Treated_day3 → Treated) and can be edited under each file.
Separate genes with commas, spaces or new lines. Matching ignores case. Use * as a wildcard (for example HOX*). Press Enter to search, Shift+Enter for a new line.

Summary

Highlighted cells pass both the padj and |log2FC| cutoffs. Group columns are mean normalized counts. The sign of log2FC follows the contrast used to make each file.
